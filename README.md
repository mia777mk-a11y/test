# غيم — دفتر ملاحظاتي ☁️

دفتر ملاحظات عربي باتجاه RTL، بألوان سماوية وخطّي Aref Ruqaa Ink وAlexandria. صُمم ليكون مكانًا تفتحين فيه ملاحظة جديدة وتكتبين بحرية؛ يحفظ النص تلقائيًا بعد توقف قصير عن الكتابة.

## الميزات

- إنشاء ملاحظة جديدة فورًا، وبدء الكتابة دون نموذج منفصل أو زر حفظ إلزامي.
- حفظ تلقائي محلي وإظهار حالة الحفظ، مع عدّاد الكلمات والحروف.
- تعديل الملاحظات، البحث في العنوان والنص، والترتيب بحسب آخر تعديل أو تاريخ الإنشاء أو العنوان.
- تصنيف الملاحظات إلى يومياتي وأفكار صغيرة وعام، وإضافة المفضّلة.
- سلة محذوفات مع الاستعادة والحذف النهائي.
- تصدير نسخة احتياطية JSON واستيرادها ودمجها مع الملاحظات الموجودة.
- الوضع الليلي، وضع التركيز، اختصارات لوحة المفاتيح، وواجهة متجاوبة.
- Service Worker لتخزين ملفات التطبيق الأساسية والعمل دون اتصال بعد أول زيارة ناجحة.
- ترحيل بيانات من إصدار غيم السابق ومفاتيح التخزين الشائعة في NoteStack.

## التشغيل والنشر

التطبيق ثابت ولا يحتاج إلى خادم API أو قاعدة بيانات. يمكن فتح `index.html` محليًا، لكن ميزات التثبيت والعمل دون اتصال تتطلب سياق HTTP/HTTPS.

لنشره على GitHub Pages:
1. افتحي **Settings → Pages** في المستودع.
2. اختاري **GitHub Actions** كمصدر النشر (workflow موجود في `.github/workflows/pages.yml`).
3. انتظري انتهاء تشغيل workflow، ثم افتحي الرابط الذي يظهر في صفحة Pages.

## البيانات والخصوصية — مهم

الملاحظات تُحفظ في `localStorage` داخل المتصفح وعلى الجهاز نفسه. لا توجد حسابات أو مزامنة سحابية أو قاعدة بيانات، ولا تُرسل الملاحظات إلى GitHub. هذا يعني أنها لا تنتقل تلقائيًا إلى جهاز آخر، وقد تُفقد إذا مُسحت بيانات المتصفح أو تغيّر المتصفح/النطاق. استخدمي تصدير النسخة الاحتياطية بانتظام. هذا التطبيق ليس مخزنًا مشفرًا؛ لا تكتبي فيه كلمات مرور أو معلومات شديدة الحساسية.

## الخطوط والاتصال

يحمّل التطبيق خطّي Aref Ruqaa Ink وAlexandria من Google Fonts عند توفر الإنترنت؛ يعمل المحتوى الأساسي دون الخطوط الخارجية.
